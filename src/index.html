How to contribute

Fork it. Cast it. It is yours.

No central registry, no pull request to ask for — a fork is a reliquary of its own, still connected to the one it came from.

01

Fork

Fork this reliquary on GitHub and clone your fork. Rune comes in with Composer.

git clone https://github.com/<you>/reliquary
cd reliquary
composer install
02

Initiate

Your fork still holds the records of its parent. Make them yours — your name, your reliquary.

php relic initiate
php nexus initiate
php hall sync
03

Register

Record your relics — sealed snapshots of your runites — then push. Your registry is what you push.

php relic register
php relic upgrade
git push
Keep it alive php hall sync php hall analize php nexus update php cast build
